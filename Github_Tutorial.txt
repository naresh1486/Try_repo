git push origin main
    commits all changes of a local directory to the global directory on github

git pull origin main
    to get all the changers after pull from remote to local

git diff main
to check diff between current branch and main branch

git add <-Filename->
to make it ready to be commited
example: git add "index.html"

git add .
to add multiple changes

git commit -m "some message"
to commit a file

git status
shows the status of each file
untracked,modified,staged,modified

git clone <-some link->
to clone directory from global to local

cd:change directory

cd ..
to get out of current directory

mkdir 
to make new directory

git init 
to initialize a directory to be a git directory

git remote add origin <-link->
to connect the already present project(directories) with the github
first add commit then this command

git remote -v
to check with what global/remote directory this local directory has been connected with

git branch 
to check the branch we are working on

git branch -M main
to rename branch 
here we renamed the branch to main

git checkout <-branch name->
to move to another branch

git checkout -b <-new branch name->
to create new branch

git branch -d <-branch name->
to delete a branch


git push -u origin main
to tell that we will push everything on the main branch only from now on 
it makes push command short from next onwards
git push

git merge <-branch name->
to merge one branch into another(main)

and after merging all the branches into main then push the main into github main branch

accept incoming change: to accept changes from main branch

accept current change: to accept changes from new branch(ie feature1 to main branch)

undo:

Case1: staged changes(to undo smth which we added but we shouldnt have added, used after the git add . command, for ex we removed a button and then git add . and we need to undo the add command)

git reset <-filename->

git reset
(to undo everything before last commit)

Case2:committed changes(for one commit)
(to undo commit, after add we also committed)

git reset HEAD~1



Case3:committed changes(for many commits)
(to undo many commits)

git reset <-commit hash->
to reset the commit to many commits before(only on git/git log history)

git reset --hard <-commit hash->
to reset the commit to many commit before(on the VS code editor, first reset on git then reset on code editor)

git log 
to get log of all the commits and their hash
